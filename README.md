# CyberSafe — Cybersecurity Awareness Website

## Project overview
CyberSafe is a beginner-level educational website designed to help users recognise common online risks and practise safer digital habits. It includes information about phishing, password security, unsafe downloads, security tips and a five-question interactive quiz.

## Technologies
- HTML5 for semantic page structure
- CSS3 for layout, visual design and responsive styling
- Vanilla JavaScript for quiz interaction, answer feedback, score calculation and mobile navigation

## Features
- Responsive layout for desktop and mobile
- Navigation links to the main content sections
- Cybersecurity awareness content
- Five-question quiz with answer feedback and final score
- Restart quiz feature
- Links to reputable online safety resources

## How to run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Navigate to the quiz and test each question, score and restart feature.

No build tools or external JavaScript libraries are required.

## Testing
Complete the test cases in `TESTING.md` and record the actual results from your own browser tests before submitting the project.

## Limitations and future improvements
This is an educational front-end prototype. It does not store quiz scores, authenticate users or connect to a server. Future work could include accessibility testing with assistive technology, more quiz questions, a content-management workflow and user feedback.
